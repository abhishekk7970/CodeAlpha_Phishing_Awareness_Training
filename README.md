# CodeAlpha Phishing Awareness Training

## Project Overview

This project is a phishing awareness training presentation developed as part of the CodeAlpha Cyber Security Internship.

## Topics Covered

- What is Phishing?
- How Phishing Works
- Types of Phishing
- Identifying Phishing Emails
- Detecting Fake Websites
- Social Engineering Tactics
- Real-World Phishing Scenario
- Phishing Prevention and Safety Practices
- What to Do After Clicking a Phishing Link
- Interactive Quiz

## Objective

The objective of this training is to help users recognize phishing attempts, understand social engineering techniques, and follow safe cybersecurity practices.

## Deliverable

The complete training presentation is available in the PDF included in this repository.
